# Documentation

Start with the PRD for *what* and *why*, then the design doc for *how*.

| Document | Purpose |
|---|---|
| [PRD](prd.md) | Problem, goals, user stories, invariants, non-functional requirements |
| [Design doc](design-doc.md) | Architecture, data model, core flows, concurrency, failure analysis, API |
| [ADRs](adr/README.md) | One record per significant decision |
| [Threat model](threat-model.md) | STRIDE analysis with mitigations |
| [Diagrams](diagrams/README.md) | C4, ERD, sequence, state and data-flow diagrams |
